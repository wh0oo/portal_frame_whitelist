# Amethyst Portals

Amethyst Portals is a Fabric mod for Minecraft 26.2 that allows Nether portals to be built with any mix of vanilla obsidian and amethyst blocks.

Vanilla obsidian portals continue to work normally. Amethyst blocks can be used anywhere obsidian would normally be accepted as part of a Nether portal frame, including mixed obsidian/amethyst frames.

## Version

1.0.0 for Minecraft 26.2
